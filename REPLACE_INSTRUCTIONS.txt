HOW TO APPLY
1. Stop the converter in PowerShell using Ctrl + C.
2. Open your existing converter project folder.
3. Extract this ZIP directly inside that project folder.
4. When Windows asks, choose "Replace the file in the destination".
5. Start the converter again using:
     npm start
6. Generate the PDF again. Previously generated PDFs will not change automatically.
